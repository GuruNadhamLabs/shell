# CyberShell 🐚

A browser-based terminal simulator built with **HTML, CSS, and JavaScript**.

CyberShell mimics a Linux-style shell interface with custom commands, command history, keyboard navigation, and a virtual filesystem concept — without executing real operating-system commands.

## Features

- 🖥️ Terminal-style UI
- ⌨️ Interactive custom commands
- ↕️ Up/down command history
- 📁 Virtual filesystem output
- 📱 Responsive design
- 🔒 Safe browser-only simulation
- ⚡ No frameworks or dependencies

## Commands

```text
help
about
whoami
ls
skills
projects
date
clear
```

## Run locally

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/GuruNadhamLabs/shell.git
cd shell
```

Then open `index.html`.

## Purpose

This project is a portfolio experiment exploring how shell concepts can be represented as a web interface. It is intentionally a **simulator** and does not execute arbitrary commands on a server.
